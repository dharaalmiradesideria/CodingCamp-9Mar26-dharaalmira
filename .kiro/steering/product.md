# Product Overview

The Productivity Dashboard is a lightweight, browser-based productivity tool that combines essential features into a single interface. It provides a time-aware greeting, a 25-minute focus timer (Pomodoro technique), a to-do list manager, and a quick links organizer.

The application is designed for simplicity and accessibility - it runs entirely in the browser with no backend, no installation, and no external dependencies. All user data (tasks and links) persists locally using the browser's Local Storage API, ensuring privacy and offline functionality.

Target users are individuals seeking a minimal, distraction-free productivity tool that works immediately without setup or account creation.
